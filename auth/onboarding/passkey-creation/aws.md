# Passkey creation AWS strategy

**Baseline:** The [Pulumi Go stack](https://github.com/lambdawalker/go.onboarding/tree/feat/aws-onboarding/infra) configures a Cognito user pool for WebAuthn, an API Lambda, and an HTTP API. The baseline exposes `/passkeys/options` and `/passkeys/complete`. Verify the deployed user-pool settings and API implementation in a nonproduction stack before wiring clients.

1. **Cognito settings:** Configure the intended relying-party ID and supported authenticators on the existing user pool. Align production HTTPS origin, Android Digital Asset Links, and iOS Associated Domains with that RP ID. Confirm the app client and authenticated access token include the scope needed for Cognito user registration APIs.
2. **Authenticated API:** Make both Go routes require the caller's Cognito access token. Relay registration option and completion requests to Cognito `StartWebAuthnRegistration` and `CompleteWebAuthnRegistration`; bind the operation to that token's account. Return only the platform options and minimal completion status to the client. Cognito is the credential registry; avoid a parallel credential table unless a separate product requirement emerges.
3. **Failures and observability:** Distinguish expired sessions, unsupported platform behavior, cancelled local UI, and Cognito registration errors. Allow fresh attempts, and preserve email OTP sign-in if setup is deferred. Log request IDs and coarse outcomes without access tokens, credential payloads, challenges, or personal data. Grant the API Lambda only the Cognito access it needs.
4. **Verification:** Exercise web, Android, and iOS origin/app association, a registered credential sign-in, cancellation, duplicate attempts, expired challenge, and session expiry. Only display “passkey added” after Cognito confirms completion. No additional AWS service is required solely for a client-side loading or failure screen.

AWS references: [StartWebAuthnRegistration](https://docs.aws.amazon.com/cognito-user-identity-pools/latest/APIReference/API_StartWebAuthnRegistration.html), [CompleteWebAuthnRegistration](https://docs.aws.amazon.com/cognito-user-identity-pools/latest/APIReference/API_CompleteWebAuthnRegistration.html), and [user-pool authentication flows](https://docs.aws.amazon.com/cognito/latest/developerguide/authentication-flows-selection-sdk.html).
